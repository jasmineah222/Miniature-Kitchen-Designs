# Miniature-Kitchen-Designs
This repository contains multiple prototypes of CAD designs and PCB designs to make innovative miniature furniture, using toy making as a practical application of CAD modeling skills.

# Project Overview 
***This project focuses on the end-to-end development of innovative, small-scale kitchen furniture (1:6 scale). The goal is to blend aesthetic "toy-like" form factors with professional-grade engineering, specifically focusing on ECAD/MCAD co-design using Autodesk Fusion 360.***

# Engineering Workflow
  Mechanical Design (MCAD): Custom 3D-modeled bodies created in Fusion 360, designed with internal mounting bosses and clearances specifically for the custom PCBs.

  Electrical Design (ECAD): PCB layouts developed to accommodate proper placing of electronic components (Example: LED lights soldered on bottom side of PCB to correct orientation of switch placement and light placement for fridge shape.)
